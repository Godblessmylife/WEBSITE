# Модули и библиотеки проекта

Документ описывает все 72 прямые зависимости из [package.json](../package.json), установленные в `node_modules` (проверено — все присутствуют физически). Транзитивные подзависимости (ещё ~530 пакетов в `node_modules`) сюда не включены — это внутренние зависимости перечисленных ниже библиотек.

Дата аудита: 2026-07-24.

## ⚠️ Пакеты, требующие вашего внимания

При аудите обнаружены зависимости, которые выглядят нетипично для 3D-сайта на Three.js и, возможно, попали в проект случайно (опечатка при установке, копипаст, или неймсквоттинг-пакет). Ничего не удалял — на ваше решение:

| Пакет | Версия | Проблема |
|---|---|---|
| **"24"** | 0.0.0 | Пакет буквально называется `"24"`, без описания и версии. Похоже на случайную установку (например, опечатка вместо номера или другого имени пакета). Рекомендую проверить, зачем он был поставлен, и, если не нужен — удалить. |
| **ui-ux-pro-max-cli** | 2.11.0 | Это CLI-утилита "для установки UI/UX skill для AI-ассистентов", а не библиотека для рантайма сайта. Скорее всего попала в зависимости по ошибке (должна быть в devDependencies инструментов разработки, если вообще нужна в проекте). |
| **xyz3d** | 0.0.7 | Малоизвестный TypeScript-фреймворк для Three.js-сайтов с Blender-интеграцией — потенциально дублирует функциональность three.js/@react-three стека. Стоит решить, используете ли вы его осознанно или он не нужен. |
| **transformers** | 1.8.3 | Название совпадает с популярной ML-библиотекой Hugging Face Transformers, но по факту это библиотека строковых трансформаций — легко перепутать намерение при установке. Проверьте, тот ли пакет вы имели в виду. |
| **react** (отсутствует в package.json) | 19.2.7 в node_modules | `react` физически установлен и активно используется (react-dom, весь стек @react-three/*, framer-motion работают поверх него), но нигде не объявлен как прямая зависимость в package.json — держится только как транзитивная зависимость. Риск: при обновлении других пакетов версия react может измениться без вашего контроля. Рекомендую явно добавить `"react": "^19.2.7"` в package.json. |

## Структура зависимостей vs структура проекта

Ниже — как категории библиотек соотносятся с папками будущего сайта (см. `Future3D/`):

- **scenes/** → three, @react-three/fiber, @react-three/drei
- **components/** → @react-three/uikit, embla-carousel-react, phosphor-react, react-helmet-async
- **shaders/** → glslify, glsl-noise, glsl-random, gl-matrix, simplex-noise
- **models/** → @gltf-transform/*, draco3d, meshoptimizer, @pmndrs/assets
- **animations/** → gsap, animejs, framer-motion, motion, lenis, locomotive-scroll
- **physics/** → cannon-es, ammo.js, @react-three/rapier, ecctrl
- **effects/** → postprocessing, @react-three/postprocessing, three-nebula, tsparticles, screen-space-reflections
- **sounds/** → howler, tone
- **utils/** → dayjs, nanoid, zod, detect-gpu, gl-matrix
- **assets/ fonts/ textures/** → @fontsource/*, sharp, @pmndrs/assets
